# Replit Requests

Ideas, bugs and feature requests from **Replit (or the owner, via Replit) to Claude Code**.
Replit may push a file here (or send the same content through the connector); Claude reads it, decides, and builds.

**Convention**

- One file per request: `NNN-short-slug.md`, numbered in this folder's own sequence. Start from `_TEMPLATE.md`.
- **Self-contained**: enough context to act cold, and a clear **done-when**.
- Status in the file: 🆕 open, 🚧 Claude is on it, ✅ done (with the commit that did it).
- Never put real data in a request (names, IDs, rosters): describe it, do not paste it.
